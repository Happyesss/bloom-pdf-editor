Implement Phase 1 of the Bloom PDF Signature Engine. [DONE]

Objective:
Build the signature tool infrastructure for visual signatures.

Requirements:

1. Add a new Signature tool to the editor toolbar.

2. Clicking on a page should create a new Signature object.

3. Create a Signature model containing:
   - id
   - pageIndex
   - x
   - y
   - width
   - height
   - rotation
   - opacity
   - locked
   - appearanceType
   - appearanceId

4. Signature objects should:
   - render above page contents
   - support selection
   - support moving
   - support resizing
   - support rotation
   - support delete
   - support undo/redo

5. Integrate with the existing editor selection system.

6. Follow the current architecture used for text, image, watermark, and annotation objects.

Constraints:
- No digital signing yet.
- No PDF writing changes.
- No external libraries.
- Maintain existing coding style.

Deliverables:
- Signature model
- Signature tool
- Rendering support
- Editor interactions
- Unit tests
