# Phase 1 — Core Architecture & Infrastructure
STATUS: COMPLETE

====================================================
OBJECTIVE
====================================================

Build the complete backend architecture for the Bloom Document Intelligence Engine.

This engine will eventually support:

• PDF → DOCX
• PDF → XLSX
• PDF → PPTX
• PDF → HTML
• PDF → Markdown
• PDF → EPUB

The engine should NEVER convert directly to any format.

Instead, everything must go through an Intermediate Document Model (IDM).

Architecture:

                Upload
                   │
                   ▼
          API Gateway
                   │
                   ▼
        Document Processing Engine

                   ▼
          Layout Analysis Engine
                   ▼
        Intermediate Document Model

      ▼        ▼        ▼
    DOCX     XLSX      PPTX
