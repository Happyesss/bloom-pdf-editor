# Bloom PDF Security Engine — Complete Implementation Prompt

## Project Overview

Implement a professional, enterprise-grade PDF Security Engine for the Bloom PDF Engine comparable in capability to Adobe Acrobat's document security features.

IMPORTANT:
This project is ONLY for PDF security.

DO NOT implement or modify anything related to digital signatures.

Specifically exclude:
- Digital Signature Engine
- Signature Validation
- ByteRange
- CMS / PKCS#7
- Timestamping
- LTV
- Certificate-based signing
- Signature Appearance
- Signature Fields

Those belong to the separate Signature Engine.

The Security Engine must integrate with the existing Bloom architecture while remaining completely modular.

The implementation must follow ISO 32000-2 (PDF 2.0) where applicable.

No external PDF libraries may be used.

Reuse the existing Bloom parser, object resolver, renderer, serializer, and incremental writer whenever possible.

The architecture must be scalable, testable, and suitable for future enterprise extensions.
